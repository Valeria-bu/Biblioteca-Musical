# Biblioteca Musical

Aplicación React para mostrar una biblioteca musical básica con canciones ficticias, estilo visual inspirado en playlists modernas y componentes de clase.

## Características

- Encabezado de la aplicación
- Lista de canciones con artista, álbum y duración
- Diseño visual simple y atractivo
- Mensaje en consola al cargar la app con componentDidMount

## Tecnologías

- React
- Vite
- CSS

## Instalación

1. Clona este repositorio.
2. Ejecuta:
   ```bash
   npm install
   ```
3. Inicia la app:
   ```bash
   npm run dev
   ```

## Uso

Abre la URL que muestra Vite en tu navegador para ver la aplicación.
